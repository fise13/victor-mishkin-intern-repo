# Cyber Security Guidelines

## Research & Learn

**Common threats when working remotely**
- Phishing emails, messages and fake login pages.
- Weak or reused passwords, and leaked passwords from other sites.
- Unsecured public Wi-Fi.
- Malware from untrusted downloads or links.
- A lost or stolen laptop or phone, or someone else using it while it's unlocked.

**Best practices for devices and accounts**
- Keep the operating system and apps updated.
- Use a unique strong password for each account, and two-factor authentication (2FA).
- Download software only from official sources.
- Avoid public Wi-Fi for work, or use a VPN.

**Why lock the computer when away**
Anyone nearby (at home, in a cafe, in a shared space) could read data, send messages or change settings as me. Locking takes a second and prevents this.

**Phishing and suspicious links**
- Check the sender's address and the real link (hover over it) before clicking.
- Be suspicious of urgency ("act now or your account will be closed").
- Don't enter a password after following a link from a message. Go to the site directly instead.
- Report suspicious messages to the team instead of ignoring them.

**Strong passwords and password managers**
A strong password is long (a passphrase of 12+ characters), unique, and not based on personal info. Nobody can remember dozens of unique passwords, so a password manager creates and stores them, and only one strong master password needs to be remembered.

**Why 2FA matters**
If a password leaks, the attacker still needs the second factor. It should be enabled on all work accounts, email and anything with important data. An authenticator app is safer than SMS codes, because phone numbers can be hijacked (SIM swapping).

## Reflection

**What security measures do I currently follow, and where can I improve?**
I always lock my computer when I leave it. I use 2FA tied to my phone number on my accounts, so everything is protected. To improve: move 2FA from SMS to an authenticator app where possible, and use a password manager.

**How can I make secure behaviour a habit?**
Notifications and reminders would help me, and so would seeing how little effort it takes: for example, enabling 2FA takes about one minute. When a safe step is quick and visible, it's easier to do it every time.

**What steps will I take to make sure my passwords and accounts are secure?**
I won't use the same password everywhere. Each account gets its own password.

**What would I do if I suspected a security breach?**
It depends on the account. In most cases I would log out of all sessions, change the password right away, and check what happened. For a work account I would also tell the team (via Discord) so they can check for damage.

## My new habit at Focus Bear

I will use a different password for every work account, and I will never reuse one between accounts.
